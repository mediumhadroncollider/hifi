# HiFi

HiFi is a DOM-first and CSS-first visual prototyping editor. This stage contains the initial editor shell with a topbar, side panels, and a central preview placeholder.

## Requirements

- Node.js
- pnpm

## Running locally

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Create a production build:

```bash
pnpm build
```
